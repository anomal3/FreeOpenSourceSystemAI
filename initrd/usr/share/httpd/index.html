It works

This page came from /bin/httpd, a web server running outside the kernel of FreeOS. Everything under it is ours: the Ethernet driver, ARP, IPv4, TCP and the sockets the server speaks through.

What this server does

  • Serves files from a directory, one Content-Length at a time.
  • Forwards a path prefix to another server and streams the answer back.
  • Counts itself at /metrics, in the format Prometheus reads.

Where to change it

Settings live in /etc/httpd.cfg: the port, the directory this page comes from, extra directories and what to forward where. The defaults ship with the image in /usr/share/defaults/etc/httpd.cfg.
