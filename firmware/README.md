# Чужие прошивки, которых здесь нет

В этой папке лежат двоичные прошивки устройств, которые мы не писали и не имеем
права раздавать. Поэтому в хранилище их нет — только это описание и способ их
добыть.

## Тачскрин телефона (`novatek/`)

Кристаллу NT36525B на `dandelion` (Redmi 9A) **нечего исполнять при включении**:
своей энергонезависимой памяти под прошивку у него нет, и её при каждом подъёме
панели кладёт в его ОЗУ хозяин — по той же шине SPI, по которой потом читает
касания. Это называется «host download», и без него панель молчит: загрузчик
кристалла отвечает, кто он такой, и больше ничего.

Файлов четыре — по числу поставщиков панели, которые Xiaomi ставила в этот
аппарат (DJN, HLT, EBBG, Truly). Какой из них нужен, решает имя панели, которое
загрузчик кладёт в командную строку ядра; ядро печатает его в журнал и выбирает
само.

Взять их:

```
cargo xtask phone-firmware
```

Команда кладёт сюда четыре файла по 118 784 байта из открытого хранилища
прошивочных двоичных файлов этого аппарата. Без них ядро собирается и работает,
но тачскрина на телефоне не будет — журнал скажет об этом прямо.
