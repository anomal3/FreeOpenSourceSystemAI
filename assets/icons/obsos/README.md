# Значок OBSOS

Значок браузера OBSOS (Open Browser for System Open Source, «Обсос»), 08.11.2026.
Свой рисунок, ни у кого не взятый: плитка с переходом фиолетовый → бирюзовый,
белое разомкнутое кольцо «O» («Open» — открыто справа сверху) и оранжевая
планета в разрыве, будто проходит орбитой.

Рисуется программой `make_icon.py` (Python без сторонних библиотек: формы
как функции расстояния, сглаживание 4×4, PNG через zlib) сразу в нужных
размерах — так значок чёткий и в 16 точках:

    python3 make_icon.py <каталог>

`obsos-256.png` — исходник для пакета: `xtask` переводит его в FIMG 64×64
(`icon.fimg` пакета `obsos`, поле `icon=` манифеста) — ярлык, панель задач,
меню «Пуск», уведомление об установке.
