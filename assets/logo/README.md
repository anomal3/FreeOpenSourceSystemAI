# Логотип FossAi

Из набора Романа «FossAi: логотип и обои» (нарисован с нуля, лицензия CC0;
SVG и все размеры PNG — у Романа, копия в `.bluegent/design-in/roman-1025/`).

| Файл | Что это | Где |
|---|---|---|
| `fossai-logo-128.png` | Знак с прозрачностью | кнопка «Пуск», «О системе» |
| `fossai-logo-tile-128.png` | Знак на плитке (значок приложения) | значок «О системе» |
| `*.fimg` | То же в FIMG 128×128 — вшито в ядро | `crates/kernel/src/ui/appicon.rs` |

Пересобрать FIMG: `cargo xtask wallpaper` (вместе с обоями).
