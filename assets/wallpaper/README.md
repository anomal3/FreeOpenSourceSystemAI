# Обои FossAi

`fossai-wallpaper-fhd.png` — обои 1920×1080 из набора Романа «FossAi: логотип и
обои» (нарисованы с нуля, лицензия CC0; полный набор размеров и SVG — у
Романа). `fossai-1920x1080.qoi` — то же в QOI, его ядро вшивает в себя
(`crates/kernel/src/ui/wallart.rs`) и растягивает под экран с обрезкой краёв.

Пересобрать после замены PNG: `cargo xtask wallpaper`.
